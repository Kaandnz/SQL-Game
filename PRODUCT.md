# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

- **Primary Audience:** Geliştiriciler, veri analistleri, mühendisler ve SQL öğrenmek isteyen veya bilgisini ileri seviyeye (CTE, Window Functions, Forensic Querying) taşımak isteyen kullanıcılar.
- **Operating Context:** Masaüstü öncelikli, geliştirici odaklı, tarayıcı üzerinden sıfır konfigürasyonla anında gerçek SQL yazma ortamı.

## Product Purpose

- **Amaç:** SQL'i pasif videolar izleyerek değil, gerçek ve izole bir WebAssembly PostgreSQL çekirdeği üzerinde gerçek dedektiflik vakaları çözerek derinlemesine öğretmek.
- **Başarı Kriteri:** Kullanıcının temel SELECT sorgularından başlayarak çok tablolu adli bilişim (forensics), kümülatif analitik ve optimizasyon problemlerini kendi başına çözebilir hale gelmesi.

## Positioning

- **Duolingo + LeetCode + SQL Murder Mystery + VS Code:** Sadece syntax ezberleten soyut sorular yerine, hikayeli soruşturmalar (E-Ticaret, SafeBank Fraud Detection, Grand Cyber Plaza Cinayeti), anlık pedagojik hata koçu (Error Coach), 3 kademeli ipucu cezalandırması ve tam 15 dünyalık kesintisiz müfredat.

## Core Capabilities

1. **İzole WebAssembly PostgreSQL Sandbox:** Bilgisayardaki hiçbir veritabanına dokunmayan, %100 güvenli tarayıcı içi gerçek PostgreSQL 16 motoru.
2. **Akıllı Hata Koçu (Pedagojik Geri Bildirim):** Cevabı ifşa etmeden sözdizimi, kolon eksikliği, satır sayısı uyuşmazlığı ve sıralama hatalarını analiz eden dedektif koçu.
3. **İnteraktif SQL Akademisi:** 15 konuluk görsel rehber ve tek tıkla çalışan canlı kod kutuları.
4. **Oyunlaştırma & İlerleme:** Dinamik XP, Seviye atlama, Günlük Streak takibi, 15 dünyalık Skill Tree ve rozet kupa odası.

## Critical Constraints

- **Yerel Veritabanı İzolasyonu:** Bilgisayardaki hiçbir yerel porta veya harici veritabanına bağlanılamaz.
- **Sıfır Git Push:** Otomatik GitHub push yapılmaz.
- **Performans & Dokunsallık:** Sık tekrarlanan sorgu çalıştırmalarında (`⌘+Enter`) sıfır gecikme; dokunsal buton basma hissiyatı.

## Terminology

- **Data Detective (Veri Dedektifi):** Oyuncunun rolü.
- **Soruşturma / Vaka (Case / Challenge):** SQL ile çözülmesi gereken iş/güvenlik problemi.
- **Error Coach (Hata Koçu):** Cevabı vermeden yönlendiren zeki hata analizcisi.
- **World (Dünya):** Müfredat bölümleri (World 1 - 15).
